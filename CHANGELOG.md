# Changelog — Kid Papercraft → Kid Papercraft Story Studio

This repository is an edited, reworked version of the original
[kid-papercraft](https://github.com/kaomei/kid-papercraft) by kaomei (MIT License).

## What was changed (A to Z)

- **Name / Title:** "Kid Papercraft" (birthday generator) → **"Kid Papercraft Story Studio"**
- **Description:** Birthday-only → short AND long story videos for kids, a new story every time
- **Language:** README, titles, descriptions, skills and dialogue scripts are now **all in English**
- **Purpose:** Birthday greetings are no longer the product. Birthday is 1 of 20+ story themes.
- **Characters & animation style:** KEPT exactly — same 5 IPs, same origami stop-motion look, same locked style anchor in every prompt
- **Master skill:** rewritten around a **Story Engine** (type × setting × problem × funny moment × lesson × ending) with a hard rule: never repeat a story
- **NEW — Short Video skill:** 30s (3 clips) and 60s (6 clips) structures, hook-first, for Shorts / TikTok / Reels (9:16)
- **NEW — Long Video skill:** 3 / 5 / 8-minute episode structures (18 / 30 / 48 clips), chapters, songs, audience questions, consistency lock (16:9)
- **Scripts:** full simple-English dialogue + subtitle tables, story summary, thumbnail/title/description/hashtag publishing pack with every output
- **NEW — Story Bank:** the full Story Engine lists plus 50 ready story ideas (10 per hero)
- **NEW — Kid-Safety doc:** a pass/fail checklist for every script (ages 3-8)
- **Series Mode:** episode logging and hero/lesson rotation for daily kids channels
- **Muse connection:** the master skill states exactly how Muse must behave on each request — minimal questions, smart defaults ("surprise me"), a fresh Story Mix on every run
- **Removed:** birthday-only README examples and birthday demo media references (the heavy birthday demo GIF/MP4 files are not carried into this version; add your own story demos under `assets/`)
- **Kept:** MIT license, IP/copyright disclaimer (updated from "birthday greetings" to general publishing responsibility)
