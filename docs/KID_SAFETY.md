# Kid-Safety Checklist (Ages 3-8)

Every script and prompt from this skill must pass ALL of these checks:

## Language
- [ ] Simple words, short sentences, key phrases repeated 2-3 times
- [ ] No sarcasm, insults, scary words, or adult themes
- [ ] The lesson is shown through kindness, and said once, warmly — never a lecture

## Story
- [ ] Conflict is gentle only: lost, stuck, mixed-up, wobbly, rainy, shy, forgotten
- [ ] No violence, weapons, fighting, chasing to harm, or "bad guys"
- [ ] Monsters/villains do not exist here — a "monster" is a friend who needs help
- [ ] No dangerous stunts a child could copy unsafely; rescues are calm and safe
- [ ] No sad, lonely or frightening endings — every story ends happy and calm
- [ ] Strangers are never part of the plot; adults appear only as kind helpers

## Visuals (prompt check)
- [ ] Everything is soft paper: no sharp, dark, horror or realistic-danger imagery
- [ ] Faces are cute and friendly in every clip
- [ ] Weather is playful (paper rain, paper snow), never a frightening storm/disaster

## Publishing
- [ ] Mark videos as "Made for Kids" where the platform requires it
- [ ] Do not present videos as official productions of any animation studio
- [ ] Follow the IP / copyright notice in the README before monetizing
