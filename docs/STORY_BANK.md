# Story Bank — The Story Engine Lists + 50 Ready Story Ideas

The skill builds every story from these lists (Master SKILL.md, Section 5).
Creators can also pick an idea directly from the 50 below — each one must still
be written fresh, with new dialogue, every time it is used.

## How to Keep a Daily Channel Fresh
- Rotate hero daily: SpongeBob → Peppa → Paw Patrol → Doraemon → Ultraman → repeat.
- Never use the same lesson two days in a row.
- Alternate Short and Long: e.g. Shorts Mon/Wed/Fri, a Long episode on Sunday.
- Log every episode: `Episode # · Hero · Title · Lesson` (Series Mode, Master SKILL.md §9).
